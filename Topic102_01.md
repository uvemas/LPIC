## 1 Design hard disk layout

**Weight**: 2

### Introduction
Queremos entender la relación entre dispositivos de almacenamiento, particiones, sistemas de ficheros y volúmenes.

Por comodidad llamaremos discos a los dispositivos de almacenamiento (antiguamente eran realmente discos, hoy en día no lo son).

Los discos están divididos en particiones. Se trata de subconjuntos **lógicos** que ayudan a compartimentalizar la información almacenada en el disco.

Un disco puede tener una o más particiones. La información necesaria sobre las mismas se almacena en la tabla de particiones. Para cada partición se almacena el tipo de la misma, la posición del primer y último sector, y otros detalles.

Cada partición puede contener un sistema de ficheros, que describe la manera en que la información está almacenada en la partición: los directorios, la relación entre los mismos, donde están los datos de cada fichero...

Una partición no puede ocupar varios discos. El LVM permite eliminar esa limitación combinando particiones, incluso entre discos, para formar volúmenes lógicos.

### Mount Points
Antes de que pueda accederse a un sistema de ficheros este debe montarse, es decir, asociarse a un punto concreto en el árbol de directorios, llamado punto de montaje.

El sistema de ficheros que contiene la raíz del árbol de directorios `/` se monta durante el proceso de arranque por el `initramfs`. Una vez montado ese sistema de ficheros sus datos ya están accesibles y, además, puede usarse como punto de montaje de otros sistemas de ficheros. Por ejemplo, si otra partición contiene un sistema de ficheros `/home` con los datos personales de los usuarios del sistema, para poder acceder a los datos de `/home` lo montamos sobre `/`. Ahora los datos de `/home` ya están accesibles.

Otro ejemplo. Supongamos que quiero montar un flash drive cuyo sistema de ficheros tiene como raíz `/mi_usb`. Lo normal es montar los dispositivos externos en el punto de montaje `/media/`. Una vez montado, el flash drive estará accesible en `/media/mi_usb`. Este montaje lo hace el sistema automáticamente. Si necesitamos montar algo manualmente es una buena práctica hacerlo en `/mnt/`.

### Particiones habituales

En un sistema doméstico hoy en día lo normal es tener solo una partición. En un servidor suele haber más.

#### /boot
#### /home

Para los datos personales de los usuarios. El directorio `/root` es una excepción.

#### /var

Para datos variables, que se escriben conn frecuencia: logs, pools de impresión, archivos temporales, archivos de los servidores web y de base de datos...

#### swap

Partición para paginar de RAM a disco si es necesario. Es una partición bastante diferente al resto. Tiene un tipo específico, el set-up se hace con su propia utilidad llamada `mkswap`, no se puede montar así que no podemos acceder a su contenido. No tiene un tamaño estándar.

En lugar de particiones swap Linux soporta también ficheros swap, que tienen la ventaja de que pueden aumentar su tamaño rápidamente si es necesario.
